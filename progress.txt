## Codebase Patterns
- Next.js 14 App Router, TypeScript 5, Tailwind CSS, Framer Motion, Lucide React
- CSS variables in globals.css: --background, --card-bg, --foreground, --muted, --ios-blue, --primary, --secondary, --cta, --arc-purple-pink, --arc-blue-cyan, --arc-gold, --ios-shadow, --ios-shadow-lg, --ios-shadow-sm
- 8px spacing grid in tailwind.config.ts (spacing.1=8px, spacing.2=16px, etc.)
- SF Pro Display loaded via next/font/local with system-ui fallback (preload:false to avoid 404 if fonts not present)
- node_modules NOT tracked in git (.gitignore); run npm install after clone
- Use `npx tsc --noEmit` + `npm run lint` for quality checks

  - ErrorBanner.tsx: AlertCircle icon, dismiss X button, optional retry, AnimatePresence
- Files changed: components/ui/Card.tsx, Button.tsx, Input.tsx, Toast.tsx, LoadingSpinner.tsx, ErrorBanner.tsx
- **Learnings for future iterations:**
  - Button extending ButtonHTMLAttributes causes TS conflict with Framer Motion's onDrag — define explicit props instead of spreading HTMLButtonElement attributes
  - CSS variables (var(--ios-shadow)) must be used in style prop, not as Tailwind utility values
  - useReducedMotion() returns null until mounted; treat null as false (don't reduce motion on initial render)
